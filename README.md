# Kiroo — Premium 3D Fan Deck English Topic Generator 🌺

**Kiroo** (`語`) is a cinematic English topic generation platform designed for writers, speakers, debaters, and language learners. Draw your next idea from an interactive 3D card fan deck with physical perspective, dark crimson aesthetics, and red spider lily artwork.

## 🌟 Highlights

- **3D Fan Deck Interaction**: 9-card deck arranged at the bottom-centre with GSAP-powered symmetrical fan opening, card shuffle, 3D lift, and dramatic reveal flip.
- **1,00,000+ Genuine Topics**: A vast library of over 108,000 English topics spanning:
  - **One-Word Themes**: Single profound words with poetic glosses (*Sonder*, *Kintsugi*, *Entropy*, *Metamorphosis*, etc.).
  - **Short Concepts**: 2–5 word editorial themes across 20 cultural and philosophical realms.
  - **Inquiry & Debate**: Deep questions for speaking and debate practice.
  - **Thought Experiments**: Multi-sentence moral dilemmas and speculative scenarios.
- **Red Spider Lily Environment**: Floating atmospheric petals, organic particle field, and crimson studio lighting.
- **Zero-Bloat Performance**: Combinatorial procedural engine generates 100,000+ topics in under 80ms on startup with a production bundle of just ~429 KB.
- **Keyboard Shortcuts**: Press <kbd>Space</kbd> or <kbd>Enter</kbd> to draw your next idea.
- **Accessible & Mobile-Responsive**: Fully responsive CSS 3D transforms, touch-friendly controls, and screen-reader accessible.

## 🛠️ Tech Stack

- **React 19** + **TypeScript**
- **Vite 8**
- **GSAP (GreenSock)** for timelines and spatial animations
- **CSS 3D Transforms** with hardware-accelerated perspective
- **Lucide Icons**
- **GitHub Pages** deployment workflow

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/Arikisitu/kiroo.git
cd kiroo

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
